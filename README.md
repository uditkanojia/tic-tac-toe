# Tic-Tac-Toe Game

A classic, interactive turn-based puzzle game built to demonstrate array manipulation, event handling, and real-time win validation in the browser.

## 🚀 Features
* **Turn-Based Gameplay:** Seamlessly switches player turns between 'X' and 'O' on every box click.
* **Win Pattern Checking:** Automatically scans 8 distinct winning combinations (rows, columns, and diagonals) after every move.
* **Dual Reset Controls:** Includes functional "Reset Game" and "New Game" buttons to completely wipe the board state.
* **Secure UI States:** Dynamically disables already-clicked boxes to prevent players from changing markers.
* **Scalable UI Layout:** Built using modern CSS Flexbox and responsive viewport units (`vmin`) to ensure the grid looks great on all screens.

## 🛠 Tech Stack
* **JavaScript (ES6+)** - Manages turn states, matrix winning checks, and element controls.
* **HTML5** - Structuring the interactive game grid and overlay messages.
* **CSS3** - Layout alignments, box-shadow accents, and conditional visibility transitions.
